# 05 · ตัวอย่างธุรกิจ

ระบบเดียวกันใช้ได้หลายธุรกิจ โดยเปลี่ยนแค่ **โปรไฟล์ธุรกิจ** (ไฟล์ตั้งค่า 1 ไฟล์) ไม่ต้องเขียนโค้ดใหม่

| ป้าย | ความหมาย |
|---|---|
| 🟢 ทดสอบในต้นแบบแล้ว | รันจริงด้วยข้อมูลตัวอย่าง |
| 🟡 ภาพประกอบ | แสดงแนวคิดเท่านั้น ยังไม่ได้ทดสอบ |

## 🟢 ร้านชาบูบุฟเฟต์

- **หน่วยขาย:** หัว (ราคาบุฟเฟต์ต่อคน)
- **วัตถุดิบ:** หมูสามชั้น, เนื้อวัวสไลด์, กุ้ง, ปลาหมึก, ผักรวม + ต้นทุนคงที่ (น้ำซุป น้ำจิ้ม)
- **จัดซื้อ:** ควรซื้อหมู (ถูกกว่าค่าเฉลี่ย 4.1%) · รอก่อนเนื้อวัว (แพงขึ้น 6.8%) · กุ้งใกล้หมด → ต้นทุน 104.84 บาท/หัว กำไรขั้นต้น 64.9%
- **การตลาด:** โปรช่วงบ่ายที่ร้านว่าง ส่วนลดถูกจำกัดไม่ให้กำไรต่ำกว่าเป้า
- **บัญชี:** กระทบยอดขายกับเงินโอนรายวัน

## 🟢 โรงแรมขนาดเล็ก

- **หน่วยขาย:** ห้อง-คืน
- **ของที่ซื้อ:** น้ำดื่ม, ชุดอุปกรณ์อาบน้ำ, กาแฟซอง, ไข่ไก่ (อาหารเช้า), ผลไม้, ค่าซักรีด
- **จัดซื้อ:** ซื้อน้ำดื่ม ~186 ขวด · ผลไม้ถูกลง 7.1% · รอก่อนซื้อไข่ไก่ (+10.4%) และซักรีด (+8.1%) → ต้นทุน 382.40 บาท/ห้อง-คืน กำไร 72.7% (เป้า 70%)
- **บัญชี:** 10 วัน พบยอดไม่ตรง 2 วัน (ขาด 5,600 / เกิน 4,200 จากรายการซ้ำ)

## 🟢 ร้านกาแฟสด 1 สาขา

- **หน่วยขาย:** แก้ว (120 แก้ว/วัน) · **ของที่ซื้อ:** เมล็ดกาแฟ นมสด นมข้น ไซรัป แก้ว+ฝา หลอด น้ำแข็ง
- **จัดซื้อ:** นมสดใกล้หมด ควรซื้อ ~22 ลิตร (+7.1%) · น้ำแข็งใกล้หมด → ต้นทุน 32.57 บาท/แก้ว กำไร 49.9% ต่ำกว่าเป้า 60%
- **การตลาด:** ไม่แนะนำให้ตามโปรอเมริกาโน่ 45 บาทของคู่แข่ง (กำไรจะเหลือ 27.6%)
- **บัญชี:** พบเงินขาด 650 และเงินเกิน 4,030 จากเลขอ้างอิงซ้ำ
- ไฟล์ที่รันได้: [`examples/coffee/`](../examples/coffee/) · คู่มือเต็ม: [07](07-real-use-playbooks.md)

## 🟡 ร้านวัสดุก่อสร้าง

- **หน่วยขาย:** ชิ้น / ถุง / เส้น · **ของที่ซื้อ:** ปูน เหล็ก ท่อ จากผู้ขายหลายเจ้าที่แจ้งราคาในกลุ่ม LINE
- **จัดซื้อ:** เทียบราคาระหว่างผู้ขาย และเตือนเมื่อราคาเหล็กขึ้นต่อเนื่อง เพื่อให้ตัดสินใจสต็อกเพิ่มหรือรอ
- **บัญชี:** กระทบยอดเงินเชื่อกับยอดรับจริง

## 🟡 อู่ซ่อมรถ / เต็นท์รถมือสอง (ต้องเพิ่มสูตรต้นทุน)

- **หน่วยขาย:** คัน / งานซ่อม · **ของที่ซื้อ:** อะไหล่ ยาง น้ำมันเครื่อง จากร้านอะไหล่หลายร้าน
- ต้นทุนแบบ "ราคารับซื้อรถ + ค่าซ่อมจริงต่อคัน" ไม่ตรงกับสูตรปัจจุบัน ต้องเพิ่มชนิดสูตรต้นทุนก่อน

## 🟡 ที่พักให้เช่า / นิติบุคคลอาคาร (ต้องเพิ่มสูตรต้นทุน)

- **ของที่ซื้อ:** วัสดุสิ้นเปลือง อุปกรณ์ซ่อมบำรุง และค่าจ้างช่างผ่านกลุ่ม LINE
- ใช้เอเจนต์จัดซื้อเทียบราคาได้ แต่ต้นทุนต่อห้องต่อเดือนต้องใช้สูตรใหม่

## วิธีเพิ่มธุรกิจใหม่ (แนวคิด)

```json
{
  "id": "coffee",
  "name": "ร้านกาแฟ (ตัวอย่าง)",
  "unit_name": "แก้ว",
  "price": 60,
  "target_margin": 0.65,
  "fixed_cost_per_unit": 3,
  "items": [
    { "name": "เมล็ดกาแฟ", "buy_unit": "กก.", "use_per_unit": 0.018 },
    { "name": "นมสด", "buy_unit": "ลิตร", "use_per_unit": 0.15, "perishable": true },
    { "name": "แก้ว+ฝา", "buy_unit": "ชุด", "use_per_unit": 1 }
  ]
}
```

ตัวเลขในไฟล์นี้เป็นตัวอย่างเพื่ออธิบายรูปแบบเท่านั้น
